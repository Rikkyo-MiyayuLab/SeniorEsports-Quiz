# このフォルダはなに？
 > Views : 各種画面を構成する呼び出しクラス（タイトル画面,クイズ画面,ストーリー画面等）

 このフォルダには、各種画面（Scene）を構成するクラスが格納されています。
 - 問題解答画面
 - タイトル画面
 - マップ画面 など...
 （まだ完全ではありませんが...）各画面は共通する１つの基底**Viewer**クラスを継承して作成されます。

 ```bash
./
├─Viewer.cs : 全画面（シーン）を構成するための基底クラス
├─CreditRoll : エンドロールの画面を構成するスクリプト
├─Map : ワールドマップやエリアマップを構成するクラス
├─QuizViews : 各種問題回答画面のスクリプトを格納しているフォルダ
│  ├─ClickQuiz : カードタイプ問題画面を構成するスクリプトを格納しているフォルダ
│  ├─EyeCatch : ユーザーの解答選択後に表示される画面（推理中）のスクリプトを格納しているフォルダ
│  ├─FourChoiceQuiz : 4択型問題画面を構成するスクリプトを格納しているフォルダ
│  ├─HintView : ヒント画面を構成するスクリプトを格納しているフォルダ
│  └─PhtotHunt : 間違い探し型問題画面を構成するスクリプトを格納しているフォルダ
├─RecordView : 成績画面を構成するスクリプトを格納しているフォルダ
├─SaveSlotView : ユーザーデータ選択画面を構成するスクリプトを格納しているフォルダ
├─StoryViews : ストーリー進行画面を構成するスクリプトを格納しているフォルダ
├─Title : タイトル画面を構成するスクリプトを格納しているフォルダ
├─TutorialView : チュートリアル画面を構成するフォルダ
└─UserRegister : ユーザー登録画面を構成するスクリプトを格納しているフォルダ
 
 ```
