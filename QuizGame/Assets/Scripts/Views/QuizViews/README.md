# **QuestionViewer.cs**について
各問題解答画面を構成しているクラスの基底クラスとして`QuestionViewer<QuestionType>`クラスが存在しています。
このクラスは、各問題解答画面で共通する機能や、必ず実装してほしい機能を定めたいわば解答画面を構成するコア機能を有したクラスとなります。

各問題解答画面のクラスは、この基底クラスを継承し、予め定めている必要な機能を実装していく形で開発をしています。

---

## QuestionViewerの役割
- 問題データの取得・管理
- タイマーやヒント、スキップなど共通UIの制御
- 問題の進行管理（正誤判定、次の問題への遷移など）
- 各問題タイプごとの個別UIやロジックは子クラスで実装

---

## 実装すべき抽象メソッドの説明

### 1. `Dispose()`
- 問題画面のリセットや、生成したオブジェクトの破棄、状態の初期化などを行う。
- 例：生成したカードやグリッド、選択肢ボタンなどの削除。

### 2. `GetData()`
- 現在表示すべき問題データを取得し、必要な情報をメンバ変数にセットする。
- 例：JSONからのデータロード、画像や音声リソースの読み込み。

### 3. `Render()`
- 取得したデータをもとに、画面上にUIやオブジェクトを生成・配置する。
- 例：選択肢ボタンへのテキスト設定、カードや画像の表示、BGMの再生など。

---

## 子クラスでの実装例

- **FourChoiceQuiz**  
  4択問題用のUI生成、選択肢ボタンの制御、正誤判定などを実装。

- **CardClickViewer**  
  カード型問題のカード生成・配置、カードクリック時の挙動、ペア判定などを実装。

- **PhotoHuntViewer**  
  間違い探し問題の画像表示、クリックポイントの生成・判定、残りカウント管理などを実装。

---

各問題タイプごとに、`Dispose()`, `GetData()`, `Render()`の3つのメソッドを必ず実装してください。
