## このフォルダについて
このフォルダは、ゲーム内で使う各種 C#スクリプトが格納されるフォルダです。
開発する C#ファイルは全てこのフォルダを起点として格納されます。

## サブディレクトリ
このフォルダは以下の様な構造を持ちます。
```bash
.
├── Controllers : ユーザーの入出力を扱うクラスが入る（ボタン等）
├── DevTools : 開発用ツールのソース一式
├── Manager : ゲーム全体の状態管理を行うクラス（セーブデータ管理, グローバル状態管理）
├── Models : 各種データ構造を定義したクラスやインタフェース（JSON形式、プレイヤーデータ構造）
├── Views : 各種画面を構成するクラス（タイトル画面,クイズ画面,ストーリー画面等）
└── Utils : 汎用的な関数や、使用頻度の高い処理の格納先（テキストの１文字ずつレンダリング等）
```
