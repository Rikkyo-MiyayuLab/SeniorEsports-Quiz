## このフォルダについて
このフォルダは、ゲーム内で使う各種 C#スクリプトが格納されるフォルダです。
開発する C#ファイルは全てこのフォルダを起点として格納されます。

## サブディレクトリ
このフォルダは以下の様な構造を持ちます。
```bash
./
├── DevTools : 開発用ツールのソース一式
├── Manager : ゲーム全体の状態管理を行うクラス（セーブデータ管理, グローバル状態管理）
├── Types : 各種データ構造を定義したクラスやインタフェース（JSON形式、プレイヤーデータ構造）
├── UI-Parts : 画面上のボタンなど、UIオブジェクト
├── Views : 各種画面を構成する呼び出しクラス（タイトル画面,クイズ画面,ストーリー画面等）
└── Utils : 汎用的な関数や、使用頻度の高い処理の格納先（テキストの１文字ずつレンダリングや、ボタン点滅等）
```
